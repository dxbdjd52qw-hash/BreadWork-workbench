## 三、功能模块明细

### 模块 1｜今日待办
- **字段**：任务名 / 优先级 P0·P1·P2 / 分类（学习·生活·社团·其他）/ 截止日期 / 完成状态 / 完成时间 / 备注
- **功能**：快速添加、勾选完成、逾期标红、按「今天 / 本周 / 全部」切换、今日完成率环形图
- **预置示例**：3 条（含 1 条逾期）

### 模块 2｜我的课表
- **字段**：课程名 / 教师 / 地点 / 星期 / 节次 / 周次范围（如 1–16 周）/ 单双周标记 / 备注
- **功能**：PC 周课表网格；移动端降级为「今日课程」列表；当前课程自动高亮；增删改；周次切换
- **需你提供**：开学第一周日期、每天节次时间表（默认第 1 节 08:00，每节 45 分钟）

### 模块 3｜单词打卡（含导入词汇）
- **字段**：日期 / 所属词书 / 目标词数 / 已背词数 / 用时 / 是否打卡 / 连续天数
- **打卡功能**：一键打卡、今日进度环（内联 SVG）、连续打卡天数、近 30 天热力图、周 / 月累计词数柱状图
- **导入词汇**：
  | 格式 | 说明 |
  |---|---|
  | CSV | `单词,音标,释义,例句`，自动识别中英文表头 |
  | TXT | 每行 `word 释义` 或单 `word` |
  | Excel | 复制粘贴，自动按 Tab 解析 |
  | JSON | `[{word, phonetic, meaning, example}]` |
  - 支持多本词书切换、按单元分组、导入自动去重、导入前预览前 10 条
  - 背诵模式：卡片式（认识 / 不认识）+ 听写模式（可选）
- **需你提供**：一个词表样例文件，确认字段格式

### 模块 4｜考研学习进度
- **三 Tab**：数学（高数·线代·概率论）｜英语（词汇·阅读·写作·翻译）｜政治（马原·毛中特·史纲·思修法基·时政）
- **字段**：条目名 / 状态（未开始·进行中·已掌握）/ 进度百分比 / 计划完成日期 / 备注
- **功能**：总体进度环、各科目进度条、一键调整百分比、落后预警（计划日期已过但未完成 → 标红）

### 模块 5｜复盘笔记
- **字段**：日期 / 类型（日复盘·周复盘）/ 今日完成 / 问题与不足 / 改进措施 / 明日计划 / 心情
- **功能**：时间倒序列表、按类型筛选、一键插入空白模板、字数统计、**「请 AI 生成草稿」按钮**（读取当天数据自动填）

### 模块 6｜数据总览（新增）
- **数据卡（4 张）**：今日任务完成率 · 连续打卡天数 · 本周学习时长 · 考研总进度
- **图表（4 个，全部内联 SVG 手写）**：
  1. 近 7 / 30 天任务完成趋势（折线，可切时间范围）
  2. 单词打卡热力图（近 12 周）
  3. 三科进度对比（横向条）
  4. 时间分配（环形）
- **「让 AI 解读」按钮** → 调 `POST /api/ai/analyze`，返回结构化建议

### 模块 7｜DDL 倒计时清单（新增）
- **字段**：事项名 / 类型（考试·作业·竞赛·报名·其他）/ 截止日期时间 / 剩余天数（自动算）/ 紧急度（自动分档）/ 关联待办 / 完成状态
- **自动分档规则**：
  | 剩余天数 | 档位 | 展示 |
  |---|---|---|
  | < 0 | 已过期 | 深红 + 置顶 |
  | 0–3 | 紧急 | 红色 + 进「今天要处理」 |
  | 4–7 | 临近 | 橙色 |
  | 8–30 | 关注 | 常规 |
  | > 30 | 远期 | 灰色 |
- **功能**：按剩余天数升序、列表 / 日历双视图切换、点击转为待办、预置「考研初试 / 四六级 / 期末周」

### 模块 8｜AI 学习助手 · 对话窗口（新增）
- **形态**：右下角悬浮按钮 → 抽屉式对话窗（PC 右侧滑出，移动端全屏）；快捷指令气泡 4 个，点一下即发
- **能力**：
  1. **问我数据** —「我这周背了多少单词？」→ 自动读取当日/本周数据拼进上下文
  2. **查待办** —「今天还有什么没做？」「哪些逾期了？」
  3. **出建议** —「数学进度落后了，帮我重排这周计划」
  4. **写复盘** —「根据今日数据生成复盘草稿」→ 一键回填到复盘笔记
- **上下文注入**：把待办 / 课表 / 打卡 / 进度 / DDL 压缩成结构化 JSON 作为 system context（只传必要字段，控制 token）
- **会话管理**：多会话、历史记录存本地 + 云端、支持清空
- **工程要求**：SSE 流式输出、失败重试、超时降级、**未配置接口时展示引导态而非报错**

## 四、后端接口契约（预留，前后端共同遵守）

> 前端**只调 `API.*`，页面里不出现裸 `fetch`**。切换后端只改一处配置。

### 4.1 前端配置层
```js
const API_CONFIG = {
  mode: 'library',            // 'library'（WorkBuddy 资料库）| 'custom'（阿里云自建）
  baseUrl: '',                // 切阿里云时填 https://api.你的域名.com
  aiChatPath: '/api/ai/chat',
  useSSE: true
};
```

### 4.2 认证
| 方法 | 路径 | 说明 |
|---|---|---|
| POST | `/api/auth/login` | 账号密码 / 验证码 → `{token, refreshToken, expiresIn}` |
| POST | `/api/auth/refresh` | 刷新令牌 |
| GET | `/api/me` | 当前用户信息 |

### 4.3 数据同步（同一套 CRUD 契约覆盖所有集合）
集合名：`todos` / `courses` / `wordBooks` / `wordLogs` / `progress` / `notes` / `ddls` / `chatSessions` / `meta`

| 方法 | 路径 | 说明 |
|---|---|---|
| GET | `/api/data/:collection?since=<iso>` | 增量拉取 |
| POST | `/api/data/:collection` | 新增 |
| PUT | `/api/data/:collection/:id` | 更新 |
| DELETE | `/api/data/:collection/:id` | 删除 |
| POST | `/api/data/sync` | 批量双向同步（冲突：`updatedAt` 新者胜，新增内容全部保留） |
| GET | `/api/data/snapshot` | 全量快照（首次登录 / 换设备） |

### 4.4 单词
| 方法 | 路径 | 说明 |
|---|---|---|
| POST | `/api/words/import` | `{bookName, format, content}` → `{imported, duplicated, failed}` |
| GET | `/api/words/books` | 词书列表 |
| GET | `/api/words/books/:id/words` | 分页取词 |
| PUT | `/api/words/recite` | 上报单个词掌握情况 |

### 4.5 AI
| 方法 | 路径 | 说明 |
|---|---|---|
| POST | `/api/ai/chat` | `{sessionId, messages, context}` → `text/event-stream` |
| POST | `/api/ai/analyze` | `{scope:'week'|'month', payload}` → `{summary, issues[], suggestions[]}` |
| POST | `/api/ai/plan` | `{goal, deadline, current}` → 生成周计划 |
| POST | `/api/ai/review` | `{date, payload}` → 复盘草稿 |
| GET | `/api/ai/sessions` | 会话列表 |

### 4.6 系统
| 方法 | 路径 | 说明 |
|---|---|---|
| GET | `/api/health` | 健康检查 |
| GET | `/api/config` | 下发公开配置 `{aiEnabled, modelName, syncMode}` |

### 4.7 安全红线
- `DASHSCOPE_API_KEY` **只能放服务端环境变量**，绝不写进前端或提交到仓库
- 资料库过渡模式下若需前端直连，Key 仅存 localStorage，且页面明确标注风险提示
- 所有接口走 HTTPS，登录态用 token 而非明文账号

## 五、阿里云部署方案（模式 B）

| 项目 | 建议配置 | 备注 |
|---|---|---|
| 服务器 | 轻量应用服务器 2 核 2G（学生认证有优惠） | 以官网实际价格为准 |
| 数据库 | 数据量小，ECS 内自建 MySQL / SQLite 足够；上量再换 RDS | — |
| 域名 | `.com` / `.cn` | **国内节点必须 ICP 备案，约 7–20 个工作日** |
| HTTPS | 免费 SSL 证书 + Nginx 反向代理 | — |
| 后端 | Node.js + Express 或 Python + FastAPI | 实现第四章全部接口 |
| AI | 阿里云百炼 DashScope，`qwen-plus`，OpenAI 兼容接口 | 新用户有免费额度，按 token 计费 |
| 对象存储 | 阿里云 OSS（可选，存图片 / 音频） | 暂不需要 |

**部署链路**：ECS 安装 Node → 上传后端代码 → 配 Nginx 反代 + HTTPS → 写环境变量 Key → 前端 `API_CONFIG.baseUrl` 指向域名。
**数据迁移**：资料库模式跑一段时间后，用 `GET /api/data/snapshot` 导出 → 导入阿里云库，无缝切换。

> ⚠️ **成本提醒**：如果只是「手机电脑数据共享」，WorkBuddy 资料库已免费做到，可以不买服务器。架构已做接口抽象，将来切换只改一行 `baseUrl`。
